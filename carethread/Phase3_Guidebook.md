# PHASE 3 (WEEKS 5–6): The Clinician Interface

Phase 1 built the data layer. Phase 2 built the brief. Phase 3 is the only part a judge will actually see, and it has to carry one argument: every sentence on the screen can be traced back to a row in the database.

That argument is also the answer to the hardest question you'll be asked. "How do I know the AI didn't make this up?" is not answered by a verification score in a technical memo. It's answered by a clinician clicking a care gap and seeing `care_gaps · HEDIS CDC-HbA1c · 314 days overdue · last 2025-11-02` appear underneath it.

---

## The design decision that shapes everything else

There are two ways to build source attribution, and the wrong one is more obvious.

The obvious approach asks the model to emit source IDs alongside each claim — `{"gap": "...", "source_id": 47}`. Don't. You'd be asking the component you don't trust to certify its own output, and a fabricated row ID looks exactly like a real one. You'd have added hallucination surface in the name of reducing it.

The approach here computes provenance after the fact. `provenance.py` takes the finished brief and the same patient data the prompt was built from, and matches each element back to its source row deterministically — the same term-overlap matching `review_brief.py` already uses. The model is never asked where a claim came from. Anything that fails to match is rendered as `unverified` rather than quietly displayed as fact.

Say this plainly in the technical memo. It's an architectural claim, not a feature: **provenance is computed from source data, never generated by the model.**

## Step 2: Create `provenance.py`

This is the heart of Phase 3. It takes a brief and the patient data, and returns the same brief with every element carrying the source rows that justify it.

Four kinds of tracing happen here:

- **Structured elements** (care gaps, medication alerts, conditions, medications) match against the corresponding table. A care gap also cites the condition that qualified the patient for it, so a clinician can see *why* the rule fired.
- **Priority actions** match to a gap first, then a condition, then any lab value they quote.
- **Prose** — the summary and recent-activity paragraphs — gets split into segments, where numbers matching stored lab values and names matching conditions or medications become hoverable spans.
- **Unmatched numbers** in prose get flagged, using the same logic as `review_brief.py`.

The `coverage` figure it returns (`14/14 claims traced`) is what the brief view displays as a badge.

**Create `provenance.py`:**

```python
"""
provenance.py — Resolve every element of a generated brief back to the
database rows it came from.

The model never emits source IDs. Matching happens here, deterministically,
against the same tables the prompt was built from. Anything that can't be
traced is marked unverified rather than quietly rendered as fact.

Usage:
    from provenance import annotate_brief
    annotated = annotate_brief(brief, patient_data)
"""

import re

STOP = {"of", "the", "a", "an", "and", "or", "for", "to", "in", "on", "with",
        "disorder", "finding", "situation", "history",
        "overdue", "due", "order", "schedule", "needed", "recommended"}

# Numbers that are standalone measurements, not digits inside a word like HbA1c
NUMBER = re.compile(r"(?<![A-Za-z0-9])\d+(?:\.\d+)?(?![A-Za-z0-9])")


def words(text):
    return set(re.sub(r"[^a-z0-9 ]", " ", str(text).lower()).split()) - STOP


def best_match(needle, candidates, key=None, threshold=0.6):
    """
    Loose term-overlap match, scored against the shorter of the two term sets.
    `key` extracts the comparable string from each candidate.
    Returns the matching candidate, or None.

    (review_brief.py carries its own copy of this. Kept separate on purpose —
    the Phase 2 checker and the UI shouldn't break each other.)
    """
    nw = words(needle)
    if not nw:
        return None
    best, best_score = None, 0.0
    for cand in candidates:
        text = key(cand) if key else cand
        hw = words(text)
        if not hw:
            continue
        score = len(nw & hw) / min(len(nw), len(hw))
        if score > best_score:
            best, best_score = cand, score
    return best if best_score >= threshold else None


# ── Source record builders ────────────────────────────────────────────────

def _src(table, label, detail="", date="", code=""):
    return {"table": table, "label": label, "detail": detail,
            "date": date, "code": code}


def _condition_src(c):
    return _src("conditions", c["condition"],
                f"Active diagnosis since {c['since']}" if c.get("since") else
                "Active diagnosis",
                c.get("since", ""), c.get("snomed_code", ""))


def _med_src(m):
    return _src("medications", m["medication"],
                f"Prescribed {m['prescribed']}" if m.get("prescribed") else "",
                m.get("prescribed", ""), m.get("rxnorm_code", ""))


def _lab_src(l):
    return _src("observations", f"{l['test']}: {l['value']} {l['unit']}".strip(),
                f"Recorded {l['date']}", l.get("date", ""),
                l.get("loinc_code", ""))


def _gap_src(g):
    bits = [g.get("guideline", "")]
    if g.get("days_overdue"):
        bits.append(f"{g['days_overdue']} days overdue")
    if g.get("last_date"):
        bits.append(f"last {g['last_date']}")
    return _src("care_gaps", g["gap"], " · ".join(b for b in bits if b),
                g.get("last_date", ""))


def _ix_src(ix):
    return _src("drug_interactions",
                f"{ix['drug_a_generic']} ↔ {ix['drug_b_generic']}",
                f"{ix['severity'].title()} · DDInter · "
                f"prescribed as {ix['drug_a']} / {ix['drug_b']}")


# ── Element-level tracing ─────────────────────────────────────────────────

def trace_conditions(brief, data):
    out = []
    for item in brief.get("key_conditions", []):
        m = best_match(item.get("condition", ""), data["conditions"],
                       key=lambda c: c["condition"])
        out.append({**item, "sources": [_condition_src(m)] if m else []})
    return out


def trace_medications(brief, data):
    out = []
    for item in brief.get("current_medications", []):
        m = best_match(item.get("medication", ""), data["medications"],
                       key=lambda x: x["medication"])
        out.append({**item, "sources": [_med_src(m)] if m else []})
    return out


def trace_alerts(brief, data):
    out = []
    for item in brief.get("medication_alerts", []):
        pair = " ".join(item.get("drugs", []))
        m = best_match(pair, data["drug_interactions"],
                       key=lambda ix: f"{ix['drug_a_generic']} {ix['drug_b_generic']}")
        sources = [_ix_src(m)] if m else []
        if m:   # also cite the two prescriptions themselves
            for drug in (m["drug_a"], m["drug_b"]):
                med = best_match(drug, data["medications"],
                                 key=lambda x: x["medication"])
                if med:
                    sources.append(_med_src(med))
        out.append({**item, "sources": sources})
    return out


def trace_gaps(brief, data):
    out = []
    for item in brief.get("care_gaps", []):
        m = best_match(item.get("gap", ""), data["care_gaps"],
                       key=lambda g: g["gap"])
        sources = [_gap_src(m)] if m else []
        if m and m.get("condition"):
            cond = best_match(m["condition"], data["conditions"],
                              key=lambda c: c["condition"])
            if cond:
                sources.append(_condition_src(cond))
        out.append({**item, "sources": sources})
    return out


def trace_actions(brief, data):
    """Priority actions trace to a gap, else a condition, else nothing."""
    out = []
    for text in brief.get("priority_actions", []):
        gap = best_match(text, data["care_gaps"], key=lambda g: g["gap"])
        if gap:
            out.append({"text": text, "sources": [_gap_src(gap)]})
            continue
        cond = best_match(text, data["conditions"], key=lambda c: c["condition"])
        if cond:
            out.append({"text": text, "sources": [_condition_src(cond)]})
            continue

        # Actions that quote a value ("creatinine 2.7633") cite that lab
        numbers = set(NUMBER.findall(text))
        labs = [l for l in data["recent_labs"]
                if str(l["value"]).strip() in numbers]
        out.append({"text": text, "sources": [_lab_src(l) for l in labs]})
    return out


# ── Prose tracing: numbers and condition names inside sentences ──────────

def trace_prose(text, data):
    """
    Split a sentence into segments, each either plain text or a cited span.
    Numbers are matched to lab values; names are matched to conditions and
    medications. Returns [{"text": str, "source": dict|None}, ...].
    """
    if not text:
        return []

    spans = []   # (start, end, source)

    for lab in data["recent_labs"]:
        value = str(lab["value"]).strip()
        if not value:
            continue
        for m in re.finditer(rf"(?<![A-Za-z0-9]){re.escape(value)}(?![A-Za-z0-9])",
                             text):
            spans.append((m.start(), m.end(), _lab_src(lab)))

    for cond in data["conditions"]:
        # Match the distinctive part of the name, e.g. "hypertension"
        for term in sorted(words(cond["condition"]), key=len, reverse=True)[:2]:
            if len(term) < 5:
                continue
            for m in re.finditer(rf"\b{re.escape(term)}\w*", text, re.I):
                spans.append((m.start(), m.end(), _condition_src(cond)))
            break

    for med in data["medications"]:
        generic = str(med["medication"]).split()[0].lower()
        if len(generic) < 5:
            continue
        for m in re.finditer(rf"\b{re.escape(generic)}\w*", text, re.I):
            spans.append((m.start(), m.end(), _med_src(med)))

    # Drop overlaps, earliest and longest first
    spans.sort(key=lambda s: (s[0], -(s[1] - s[0])))
    kept, last_end = [], -1
    for start, end, src in spans:
        if start >= last_end:
            kept.append((start, end, src))
            last_end = end

    segments, cursor = [], 0
    for start, end, src in kept:
        if start > cursor:
            segments.append({"text": text[cursor:start], "source": None})
        segments.append({"text": text[start:end], "source": src})
        cursor = end
    if cursor < len(text):
        segments.append({"text": text[cursor:], "source": None})
    return segments


ISO_DATE = re.compile(r"\d{4}-\d{2}-\d{2}")


def untraced_numbers(text, data):
    """Numbers in prose that match no stored lab value — worth a flag."""
    text = ISO_DATE.sub(" ", text or "")   # 2025-11-02 is a date, not a value
    known = {str(l["value"]).strip() for l in data["recent_labs"]}
    known |= {str(data["demographics"]["age"])}
    source_text = " ".join([c["condition"] for c in data["conditions"]] +
                           [m["medication"] for m in data["medications"]])
    known |= set(NUMBER.findall(source_text))
    return [n for n in dict.fromkeys(NUMBER.findall(text or ""))
            if n not in known and not re.fullmatch(r"(19|20)\d{2}", n)]


# ── Top level ────────────────────────────────────────────────────────────

def annotate_brief(brief, data):
    """Return the brief with every element carrying its source rows."""
    conditions = trace_conditions(brief, data)
    medications = trace_medications(brief, data)
    alerts = trace_alerts(brief, data)
    gaps = trace_gaps(brief, data)
    actions = trace_actions(brief, data)

    traceable = conditions + medications + alerts + gaps + actions
    traced = sum(1 for item in traceable if item.get("sources"))

    return {
        "meta": brief.get("_meta", {}),
        "summary": trace_prose(brief.get("patient_summary", ""), data),
        "recent_activity": trace_prose(brief.get("recent_activity", ""), data),
        "key_conditions": conditions,
        "current_medications": medications,
        "medication_alerts": alerts,
        "care_gaps": gaps,
        "priority_actions": actions,
        "sdoh_flags": brief.get("sdoh_flags", []),
        "coverage": {
            "traced": traced,
            "total": len(traceable),
            "percent": round(100 * traced / len(traceable)) if traceable else 0,
        },
        "unmatched_numbers": (
            untraced_numbers(brief.get("patient_summary", ""), data) +
            untraced_numbers(brief.get("recent_activity", ""), data)),
        "parse_error": bool(brief.get("parse_error")),
    }
```

## Step 3: Create `app.py`

Three routes. The dashboard reads every brief in `briefs/`, re-runs verification, and ranks patients. The patient route annotates one brief. The API route returns the same thing as JSON, which is both a debugging tool and the seam a real frontend would use later.

Verification runs at request time rather than being read from a stored field. Slower, but it means the screen can never show a stale verdict — if you regenerate a brief, the dashboard reflects it on the next refresh.

**Create `app.py`:**

```python
"""
app.py — CareThread web interface.

    python app.py      → http://127.0.0.1:5000

Routes:
    /                      coordinator dashboard, patients ranked by urgency
    /patient/<id>          one brief, every claim traceable to its source
    /api/brief/<id>        the annotated brief as JSON
"""

import json
import sqlite3
from pathlib import Path

from flask import Flask, abort, jsonify, render_template

from assemble_patient import assemble_patient_data
from provenance import annotate_brief
from verify_brief import verify_brief

app = Flask(__name__)

DB_PATH = "carethread.db"
BRIEFS_DIR = Path("briefs")

SEVERITY_RANK = {"high": 0, "medium": 1, "low": 2}


def get_db():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn


def load_brief(patient_id):
    path = BRIEFS_DIR / f"{patient_id}.json"
    if not path.exists():
        return None
    return json.loads(path.read_text())


def brief_index():
    """Every brief on disk, with the numbers the dashboard ranks on."""
    conn = get_db()
    rows = []

    for path in BRIEFS_DIR.glob("*.json"):
        brief = json.loads(path.read_text())
        meta = brief.get("_meta", {})
        pid = meta.get("patient_id") or path.stem

        data = assemble_patient_data(conn, pid)
        if not data:
            continue   # brief for a patient no longer in the database

        gaps = data["care_gaps"]
        counts = {s: sum(1 for g in gaps if g["severity"] == s)
                  for s in ("high", "medium", "low")}
        report = verify_brief(brief, data)

        rows.append({
            "patient_id": pid,
            "name": data["demographics"]["name"],
            "age": data["demographics"]["age"],
            "gender": data["demographics"]["gender"],
            "gap_counts": counts,
            "gap_total": len(gaps),
            "alerts": len(data["drug_interactions"]),
            "major_alerts": sum(1 for ix in data["drug_interactions"]
                                if ix["severity"] == "major"),
            "verdict": report["verdict"],
            "issues": report["issues_found"],
            "model": meta.get("model", "—"),
        })

    conn.close()
    # Most urgent first: high gaps, then major interactions, then total gaps
    rows.sort(key=lambda r: (-r["gap_counts"]["high"], -r["major_alerts"],
                             -r["gap_total"]))
    return rows


@app.route("/")
def dashboard():
    rows = brief_index()
    totals = {
        "patients": len(rows),
        "high_gaps": sum(r["gap_counts"]["high"] for r in rows),
        "major_alerts": sum(r["major_alerts"] for r in rows),
        "flagged": sum(1 for r in rows if r["verdict"] != "PASS"),
    }
    return render_template("dashboard.html", rows=rows, totals=totals)


@app.route("/patient/<patient_id>")
def patient(patient_id):
    brief = load_brief(patient_id)
    if brief is None:
        abort(404, "No brief generated for this patient yet.")

    conn = get_db()
    data = assemble_patient_data(conn, patient_id)
    conn.close()
    if not data:
        abort(404, "Patient not in database.")

    return render_template(
        "brief.html",
        brief=annotate_brief(brief, data),
        report=verify_brief(brief, data),
        data=data,
    )


@app.route("/api/brief/<patient_id>")
def api_brief(patient_id):
    brief = load_brief(patient_id)
    if brief is None:
        return jsonify({"error": "no brief for this patient"}), 404

    conn = get_db()
    data = assemble_patient_data(conn, patient_id)
    conn.close()
    if not data:
        return jsonify({"error": "patient not in database"}), 404

    return jsonify({"brief": annotate_brief(brief, data),
                    "verification": verify_brief(brief, data)})


@app.errorhandler(404)
def not_found(e):
    return render_template("error.html", message=str(e)), 404


if __name__ == "__main__":
    if not Path(DB_PATH).exists():
        raise SystemExit(f"{DB_PATH} not found — run this from your project folder.")
    if not BRIEFS_DIR.exists():
        raise SystemExit("briefs/ not found — run run_pipeline.py first.")
    app.run(debug=True, port=5000)
```

### `templates/brief.html`

The main screen. The `cite()` macro at the top is used by every section, so attribution renders identically for a care gap, a medication alert, and a priority action. Elements with no matching source get an `unverified` badge instead of a source button — that's the honest failure mode, and it's worth leaving visible rather than hiding.

Prose uses a different mechanism: traced spans are underlined and reveal their source on hover, so the summary stays readable instead of being broken up by buttons.

## Step 5: Create `static/style.css`

Styling choices that matter for a clinical tool, in case you're asked:

- Severity is carried by **both** color and text (`high`, `major`), never color alone. Roughly 1 in 12 men has some degree of color vision deficiency, and a clinical tool that encodes urgency only in red fails them.
- Dense but not cramped. A pre-visit brief is scanned in under two minutes between patients, so the hierarchy has to work at a glance.
- Muted institutional palette rather than a consumer-app look. Red is reserved for severity and verification failure, so it means one thing on the screen.

## Step 6: Run it

```bash
python app.py
```

Open http://127.0.0.1:5000. You should see the dashboard with one row per brief in `briefs/`.

**If the page is empty,** you have no briefs — run `python run_pipeline.py --count 5` first.

**If a patient 404s,** the brief's `_meta.patient_id` doesn't match a row in `patients`. Check with:

```bash
python3 -c "
import json, glob, sqlite3
conn = sqlite3.connect('carethread.db')
for f in glob.glob('briefs/*.json'):
    pid = json.load(open(f)).get('_meta', {}).get('patient_id')
    hit = conn.execute('SELECT 1 FROM patients WHERE patient_id=?', (pid,)).fetchone()
    print(('ok  ' if hit else 'MISS'), pid, f)
"
```

**If styling doesn't load,** the file must be at `static/style.css` exactly — Flask serves `/static` from that folder only.

Flask's `debug=True` reloads on save, so you can edit a template and refresh without restarting. Turn it off before recording anything: debug mode exposes an interactive traceback console, and a crash on camera would hand a judge a Python shell on your machine.

## Step 7: Check it against a real patient

Walk one patient end to end before you polish anything:

1. **Dashboard.** Is the ranking sensible — would a coordinator agree the top patient is the most urgent one?
2. **Open the top patient.** Does the badge show a high traced percentage?
3. **Click three different `source` buttons.** Does each show the actual guideline, date, and days overdue from `care_gaps`?
4. **Hover a lab value in the summary.** Does the tooltip show the LOINC-coded observation?
5. **Open a flagged patient.** Does the verification box name the specific issue?

Step 5 is the one people skip, and it's the most important. Your demo should show a flagged brief, not only clean ones. A tool that admits when it can't verify something is more credible than one that never shows a failure, and a judge who suspects you've hidden the failures will discount the clean ones too.

## Step 8: Record the demo

The Inventacare submission is a 3–5 minute video. Structure that earns the time:

| Time | Beat |
|------|------|
| 0:00–0:30 | The barrier: a 15-minute FQHC visit, records scattered across systems, clinician reading cold |
| 0:30–1:00 | Dashboard: 380 patients scored, ranked by urgency, no chart review |
| 1:00–2:30 | One brief, start to finish. Click sources live. This is the centerpiece |
| 2:30–3:15 | The flagged patient. Verification caught an unsupported claim, and the UI says so |
| 3:15–4:00 | Architecture in three sentences: rules detect, model summarizes, verification checks, provenance proves |
| 4:00–4:30 | Deployability: runs on self-hosted models, synthetic data throughout, no PHI left the institution |

Record at 1280×720 or larger, zoom the browser to about 125% so text is legible on a laptop, and close every other tab. Say the numbers out loud — "fourteen of fourteen claims traced" lands harder than a badge nobody reads.

The 2:30 beat is the one judges will remember. Most AI healthcare demos show the happy path. Showing the failure, and showing that your system caught it unprompted, is the difference between a demo and an argument.

## If you run short on time

Cut in this order, last first:

1. **SDOH section** — nice context, not load-bearing.
2. **Prose hover tooltips** — the structured `source` buttons carry the argument on their own.
3. **The `/api/brief/` route** — invisible in the demo; keep it only if a judge asks about integration.
4. **The dashboard** — if it comes to it, a single brief page with working attribution is a stronger submission than two half-finished screens.

Never cut: source attribution on care gaps and medication alerts, and the verification badge. Those two are the submission's actual claim.
